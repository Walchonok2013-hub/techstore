Techstore — веб‑приложение интернет‑магазина с каталогом товаров, корзиной, избранным, профилями пользователей, оформлением заказов и админкой. Проект реализует базовый функционал MVP для онлайн‑торговли.

## 🛠️ Технологический стек

- Python
- Django (6.x)
- SQLite / PostgreSQL (база данных)
- HTML/CSS, шаблонизация Django
- Pydantic (в экспериментальных частях / FastAPI)
- Виртуальное окружение (venv)

## 🚀 Быстрый старт

### Требования

- Python 3.11+
- python -m venv myenv
- myenv\Scripts\activate
- pip install -r requirements.txt
- pip install Pandas
- pip install pillow
- npm jquery bootstrap
- python manage.py migrations
- python manage.py migrate
- python manage.py createsuperuser
- python manage.py runserver
